Projetos desenvolvidos

Esses são três projetos reais que desenvolvi como freela, cada um resolvendo uma dor específica de negócio. Nenhum começou com escopo fechado — todos partiram de uma conversa sobre o problema e evoluíram de forma incremental.

App mobile Flutter Android

Meu Auditor

App mobile para auditoria de conformidade em campo

O problema

Profissionais que fazem auditorias de conformidade in loco precisavam registrar itens, tirar fotos das evidências e gerar um relatório — tudo isso em papel ou em planilhas, sem uma ferramenta dedicada para campo.

O que foi construído

App mobile Flutter para Android com checklist de auditoria configurável, classificação de itens por conformidade, captura de fotos como evidência por item, armazenamento local offline e geração de relatório em PDF para compartilhamento direto pelo celular.

  • Criação e gerenciamento de múltiplas auditorias
  • Itens classificados como conforme ou não conforme
  • Fotos vinculadas a cada item do checklist
  • Geração de PDF com todos os dados e imagens
  • compartilhamento de checklist via WhatsApp
  • Funciona 100% offline — dados salvos no dispositivo

Stack utilizada

Flutter · GetX · SharedPreferences · PDF · image_picker · share_plus

Sistema desktop Flutter Windows SQLite local

Karat Gestão

Sistema desktop de gestão para joalherias

O problema

Uma joalheria precisava controlar estoque de peças, cadastro de clientes, fornecedores e movimentações de venda, com acompanhamento da cotação do ouro em tempo real para apoiar decisões de precificação — sem depender de planilhas ou sistemas genéricos que não atendiam o fluxo específico do negócio.

O que foi construído

Sistema desktop para Windows com banco de dados local, sem necessidade de servidor ou internet para operação básica. Dashboard com métricas de vendas, cotação do ouro atualizada e controle de metas mensais.

  • Dashboard com vendas do mês, comparativo e valor do estoque
  • Cotação do ouro em tempo real integrada ao painel
  • Controle de metas mensais de vendas
  • CRUD de produtos, clientes e fornecedores
  • Movimentação de estoque com histórico
  • Banco SQLite local com backup automatizado

Stack utilizada

Flutter (Windows) · Drift (SQLite) · Riverpod · HTTP

API / Backend Node.js + TypeScript IA integrada

Gado Gestor — API

Backend de sistema completo para gestão de rebanho bovino

O problema

Um app de gestão agropecuária precisava migrar toda a lógica de negócio do frontend para um backend robusto, com autenticação real, escopo por usuário, regras de negócio complexas (compra/venda de animais entre usuários do app, histórico de saúde, eventos reprodutivos) e integração com IA para cotações de mercado.

O que foi construído

API REST completa em Node.js + TypeScript com autenticação JWT, banco de dados PostgreSQL e integração com a IA para cotações de mercado de gado em tempo real.

  • Autenticação completa: login, cadastro, recuperação de senha via e-mail
  • CRUD de animais com histórico de peso e eventos sanitários
  • Gestão financeira: compra e venda de animais com estorno automático
  • Transferência de animal entre usuários do app (compra/venda com histórico)
  • Sistema de alertas automáticos gerados no backend
  • Cotações de mercado via IA
  • Banco de dados + armazenamento de arquivos online
  • Envio de e-mails

Stack utilizada

Node.js · Express · TypeScript · PostgreSQL · JWT · IA · Gmail API

Uma observação honesta

Esses três projetos foram desenvolvidos para clientes reais e estão em uso. Nenhum é um projeto de estudo — cada um resolve uma necessidade específica de negócio, com as complexidades reais que isso implica: regras de negócio que mudam, decisões de escopo no meio do caminho, integrações com serviços externos e necessidade de manutenção.

Se o teu projeto parece simples agora, provavelmente vai ganhar complexidade conforme evolui. Ter alguém que já navegou por esse caminho ajuda a antecipar decisões — e evitar retrabalho caro.
